Descrição do problema

O acesso aos serviços públicos digitais ainda apresenta dificuldades para parte da população, principalmente para pessoas com limitações visuais, motoras, baixa familiaridade com tecnologia ou dificuldades de interação com interfaces tradicionais.

O projeto Cricio busca desenvolver uma solução baseada em comandos de voz para facilitar a utilização de serviços públicos digitais, tornando o acesso mais simples, intuitivo e inclusivo.

Objetivo da solução

Desenvolver uma aplicação capaz de interpretar comandos de voz e auxiliar cidadãos no acesso a serviços públicos digitais.

A solução tem como objetivo reduzir barreiras de acessibilidade, permitindo que usuários realizem consultas e interações utilizando comandos de voz, promovendo maior inclusão digital.


Público beneficiado

A solução poderá beneficiar:

- Pessoas com deficiência visual;
- Pessoas com limitações motoras;
- Idosos com dificuldades no uso de ferramentas digitais;
- Usuários com pouca experiência tecnológica;
- Cidadãos que necessitam de uma forma mais acessível de utilizar serviços públicos.


Funcionalidades previstas para a primeira versão

1. Reconhecimento de comandos de voz
   - Permitir que o usuário interaja com o sistema utilizando fala.

2. Conversão de voz para texto
   - Interpretar os comandos enviados pelo usuário.

3. Consulta de informações em serviços públicos
   - Auxiliar o usuário na busca por informações disponíveis.

4. Retorno das informações por áudio
   - Responder ao usuário utilizando síntese de voz.

5. Interface acessível e simplificada
   - Desenvolver uma experiência intuitiva para facilitar a utilização.
